## 해석 기록
- F5: "틀린 비밀번호 5회 연속이면 60초 동안 429"는 5번째 틀린 시도까지 401이고, 6번째 시도부터 60초 동안 429로 읽는다(5절 "5회 연속 실패 후 60초"). 목업이 5번째에서 잠금 문구를 보이는 것과는 다르며 API 기준을 따른다.
- F5: 로그인 상태에서 GET /login은 /로 "이동"이면 되므로 리다이렉트 상태 코드(302·303·307)를 고정하지 않는다. 미로그인 리다이렉트는 302로 고정한다.
