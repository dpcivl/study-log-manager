## 한 일
마크다운 변환이나 정화가 실패하면 원문과 안내 문구를 보이도록 했고, S5의 수정·삭제 버튼이 항상 나온다.
원문 상자는 화면의 60%로 제한해 안에서 스크롤한다. 코드 강조만 실패하면 문구 없이 렌더 결과를 유지한다.
리뷰에서 나온 두 건도 고쳤다. 정화가 null을 돌려주는 본문과, 8겹 이상 인용에서 글 폭이 0이 되는 문제다.

## 이번에 정한 해석
- F7: 렌더는 성공해도 읽을 수 없는 깊은 인용은 F7 범위로 본다. 인용은 1~3겹까지 전과 같고, 4겹부터는 들여쓰기를 더하지 않는다. 정화가 예외 없이 문서 조각이 아닌 값을 돌려주면 정화 실패로 본다.

## 브라우저 확인 (지휘자)
pytest는 브라우저 JS를 실행하지 않으므로 아래를 실제 브라우저에서 확인했다.
- `>` 50,000자 노트의 S5: 문구, 원문 50,000자, 상자 높이 60vh, 수정·삭제 버튼
- 같은 본문의 S4 미리보기와 "편집" 복귀: 입력 50,000자 유지
- `<frameset>abc`: 문구와 원문 표시
- 인용 1·3겹은 전과 같고, 8·300겹은 폭 388px로 읽히며 가로 넘침 없음
- 코드 강조가 예외를 던져도 문구 없이 렌더 결과 유지
- 정상 노트와 코드 강조 회귀 없음
